Superstore Sales Analysis Using Power BI

Executive Dashboard – Task 2

Project Overview

This project focuses on developing an interactive Executive Dashboard using Microsoft Power BI to analyse Superstore sales and profitability.

The dashboard provides a clear overview of business performance through KPI cards, charts, treemaps, a matrix and interactive slicers.

Objectives

- Analyse total sales and profit.
- Monitor total orders and profit margin.
- Understand regional sales performance.
- Analyse product category and sub-category performance.
- Track sales trends over time.
- Support data-driven business decisions.

Tools and Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- CSV Dataset

Dashboard Features

1. Total Sales KPI
2. Total Profit KPI
3. Total Orders KPI
4. Profit Margin KPI
5. Year-over-Year Sales Growth
6. Date and Region Slicers
7. Regional Sales Treemap
8. Product Profitability Matrix
9. Sales Trend Line Chart
10. Sales Waterfall Chart
11. Category and Sub-Category Treemap

Business Insights

The dashboard helps identify sales performance, profitability, regional contributions and product performance. It supports managers in understanding business trends and making informed decisions.
